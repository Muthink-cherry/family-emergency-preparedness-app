# 家庭防災準備工具

固定網址：https://muthink-cherry.github.io/family-emergency-preparedness-app/

這是一個可直接在手機與電腦使用的家庭防災 PWA。它用來管理防災物資、庫存批次、效期、汰換紀錄、避難包與整備進度。

本工具是靜態網站，沒有雲端資料庫、會員帳號或追蹤程式。日常使用不需要維護伺服器；但若未來瀏覽器規格改變，仍可能需要相容性更新。

## 最重要的資料提醒

使用者輸入的家庭成員、物資、數量、效期與存放位置，只保存在目前裝置的目前瀏覽器中，不會上傳到 GitHub。

請養成即時備份習慣：

- 每次大量新增或修改後，立即下載一份 JSON 備份。
- 至少每月備份一次。
- 更換手機、電腦、瀏覽器，或清除網站資料前，務必先備份。
- JSON 可能含家庭資訊與物資位置，只應交給信任的家人。

操作位置：進入工具後，開啟「設定 → 備份與還原 → 下載 JSON 備份」。

## 電腦版使用與安裝

1. 使用 Chrome 或 Microsoft Edge 開啟固定網址。
2. 第一次使用時設定成人數、孩童數、準備天數與成員暱稱。
3. 在網址列右側選擇「安裝」圖示；若未顯示，開啟瀏覽器選單後選擇「安裝應用程式」。
4. 安裝後可從桌面、開始選單或應用程式清單開啟。
5. 不想安裝也可以直接保留書籤，以一般網站方式使用。

## iPhone／iPad 安裝

1. 用 Safari 開啟固定網址。
2. 點選「分享」圖示。
3. 選擇「加入主畫面」。
4. 確認名稱後點選「加入」。
5. 之後從主畫面的「家庭防災」圖示開啟。

## Android 安裝

1. 用 Chrome 開啟固定網址。
2. 點選右上角選單。
3. 選擇「安裝應用程式」或「加入主畫面」。
4. 確認後，從主畫面的圖示開啟。

## 同一家庭換到另一台電腦或手機

目前沒有即時雲端同步。請用 JSON 備份移轉：

1. 在資料最新的裝置開啟「設定」。
2. 點選「下載 JSON 備份」。
3. 將下載的 JSON 檔傳給信任的家人，可使用隨身碟、AirDrop、通訊軟體或自己信任的雲端硬碟。
4. 在另一台裝置開啟同一個固定網址並完成安裝。
5. 到「設定 → 備份與還原」，選擇「匯入備份」。
6. 選取剛收到的 JSON 檔。
7. 檢查系統顯示的物資、批次與避難包數量，確認後再還原。

匯入會用備份內容取代該裝置目前的完整資料。如果該裝置已有資料，請先下載一份備份再匯入。

## 同一家庭共同使用的建議流程

為避免資料互相覆蓋，建議指定一台裝置作為「主要資料端」：

1. 平時由主要資料端更新。
2. 需要讓其他家人取得最新版時，由主要資料端下載 JSON。
3. 其他家人只匯入最新備份。
4. 如果其他家人做了修改，先把他的 JSON 備份交回主要資料端。
5. 主要資料端確認要採用哪一份後再匯入，接著重新輸出最新版。

不要讓兩台裝置同時各自修改，再直接互相匯入。這個版本不會合併兩份資料，最後匯入的完整備份會覆蓋原有內容。

更完整的說明請閱讀：[資料備份與家庭共用](資料備份與家庭共用.md)。

## 多位使用者會不會資料混在一起？

不會。不同裝置、不同瀏覽器設定檔各有自己的本機資料。使用相同網址不代表共用同一個資料庫。

同一台裝置、同一個瀏覽器設定檔與同一網址則會使用同一份資料。共用電腦若想分開管理，請使用不同的瀏覽器設定檔。

## 可能造成資料遺失的情況

- 清除瀏覽器的網站資料或儲存空間。
- 移除瀏覽器設定檔。
- 更換手機、電腦、瀏覽器或發布網址。
- 長期只在無痕／私密模式使用。
